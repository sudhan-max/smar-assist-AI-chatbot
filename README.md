# 🤖 SmartAssist AI Chatbot

SmartAssist is an AI-powered chatbot developed using Python, Transformers, and Gradio.

## 🎯 Objective

The objective of this project is to develop an interactive AI chatbot that can understand user questions and generate suitable responses.

## 🛠 Technologies Used

- Python
- Google Colab
- Hugging Face Transformers
- Qwen2.5-0.5B-Instruct
- PyTorch
- Gradio

## ✨ Features

- Interactive chatbot interface
- Natural language question answering
- Can answer general questions
- Simple and user-friendly interface
- Runs in Google Colab
- Gradio web interface

## ⚙️ How It Works

User Question  
↓  
Gradio Interface  
↓  
Python Program  
↓  
Qwen AI Model  
↓  
Generated Response  
↓  
User

## ▶️ How to Run

1. Open the notebook in Google Colab.
2. Install the required packages.
3. Load the Qwen AI model.
4. Run the chatbot code.
5. Open the Gradio public URL.
6. Start asking questions.

## 📁 Project Files

- `SmartAssist_AI_Chatbot.ipynb` – Main Google Colab notebook
- `requirements.txt` – Required Python packages
- `README.md` – Project documentation
